# HackBot Agents

This directory contains the agent modules for the HackBot project.

## Structure

- **model/** — AI model files and configurations
- **skills/** — Customizable skill modules
- **actions/** — Action implementation and flow coordination
- **data/** — Data files and datasets
- **utils/** — Utility functions (helpers, file handling)
- **logs/** — Log and metrics files
- **docs/** — Documentation and design files

## Getting Started

1. Configure the model in `model/model_config.json`
2. Implement skills in `skills/`
3. Define actions in `actions/`
4. Use utilities from `utils/` for common operations
