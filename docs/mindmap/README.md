# hackbot mind maps

Living, text-based mind maps of the hackbot project. They grow as the project
grows, so each meaningful milestone gets its own version file.

## Versions

| File | Focus | Status |
|------|-------|--------|
| `v1-overview.txt` | Project shape at the nmap-agent milestone | current |
| `v2-*.txt` | Next milestone (see ROADMAP) | planned |
| `v3-*.txt` | Following milestone | planned |
| `final-annotated.txt` | Full version: every branch explained for a newcomer | planned |

## How to read a map

- The **tree** is the project; each **branch** is a concept; deeper = more specific.
- `-->` marks **data flow** (what becomes what).
- `[ ]` marks **status/roadmap** items.
- The **final annotated** version adds a plain-language comment under each branch.

## Keeping it current

Add a new `vN-*.txt` when a milestone lands, and update the table above. Keep
older versions untouched so the evolution is visible.
